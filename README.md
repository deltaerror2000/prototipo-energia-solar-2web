# Protótipo de energia solar — 2Web Studios

Landing page demonstrativa para empresas de energia solar. O hero é uma cena WebGL construída em tempo real com React Three Fiber: casa, painéis, terreno, vegetação, iluminação e sombras são objetos 3D, não uma imagem de fundo.

Ao rolar a página, a cena passa do dia para a noite, acende a iluminação da casa e apresenta de forma visual a geração e a compensação de energia.

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run build
```

Projeto de apresentação criado pela **2Web Studios**.
